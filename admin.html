Admin Panel de administración ← Volver a la web

1 · Conectar con tu repositorio

¿Cómo consigo el token? (una sola vez)
  1. En GitHub: tu foto → Settings → abajo Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: admin-web. Caducidad: 90 días.
  3. Repository access → Only select repositories y elige solo este repositorio.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate token y copia el texto (empieza por github_pat_). No lo compartas con nadie.

2 · Subir una carátula

Al publicar, el cambio se sube a tu repositorio y la web lo muestra en uno o dos minutos (recarga con Ctrl + F5).
